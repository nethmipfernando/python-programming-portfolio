# Image Processing
A Python programming project demonstrating basic image processing through pixel manipulation.

# Skills Demonstrated
* Arrays
* Nested loops
* Conditional statements
* Pixel manipulation
* Numerical data processing
* Image processing

# Project Description
The program reads images and processes individual pixels using loops and conditional logic. Different visual effects are created by modifying pixel values based on pixel colour and position.
