# Object-Oriented Programming: Moving Shapes
A Python programming project demonstrating object-oriented programming principles through the simulation of moving shapes.

# Skills Demonstrated
* Classes and objects
* Inheritance
* Subclasses
* Method overriding
* Functions and methods
* Conditional logic
* Random number generation
* Mathematical calculations

# Project Description
The program models moving squares, diamonds and circles. A general `MovingShape` class provides shared functionality, while specialised subclasses define shape-specific behaviour and calculations. The program uses object-oriented programming principles to control movement and bouncing behaviour.

* Python
