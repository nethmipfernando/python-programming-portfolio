# Pulse Data Analysis
A Python project demonstrating the analysis and visualisation of numerical data.

# Skills Demonstrated
* File handling
* Functions
* Lists
* Loops
* Numerical data processing
* Sorting data
* Data visualisation
* Histograms

# Project Description
This program reads numerical pulse data from a text file, converts the values into numerical data, stores them in a list and sorts the dataset. The data is then visualised using a histogram to explore its distribution.

# Technologies Used
* Python
* PyLab
